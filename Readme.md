# 📊 Students Performance - EDA

Exploratory Data Analysis on Students Performance dataset using Python, Pandas & Seaborn.

### 🔍 Overview
Analyzed factors affecting student scores - gender, parental education, lunch type, test preparation.

### 📈 8 Key Visualizations
1. Gender distribution
2. Parental education impact
3. Lunch vs Scores
4. Test preparation course effect
5. Math vs Reading correlation
6. Average score distribution
7. Race/ethnicity analysis
8. Overall performance trends

### 🛠️ Tech Stack
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

### 📂 Files
- `students_eda.ipynb` - Complete EDA with code & graphs
- `StudentsPerformance.csv` - Dataset

pip install pandas seaborn matplotlib
